Automations

Rules that act on a board for you: email someone, raise an alert, move or tag a card, call a URL, or send the card to an agent.

Ready-made rules

Every board has an Automations panel, in the board's menu, for its owner. It opens with a gallery of the rules most boards want, each set up with a short form. These need no AI model:

  • Follow : new cards, a list, one card, comments, a field changing, cards assigned to you.
  • Remind : due soon, overdue, or untouched for a number of days.
  • Tidy : complete cards that reach Done, archive old ones, let a tag set the priority, and a Weekly tidy-up that looks the board over and alerts you to what Tidy up… found, changing nothing.
  • Connect : call a URL on every change (a webhook ).

Rules in your own words

Or describe a rule in a sentence:

automatically move cards in In Progress to Backlog if they've not been touched for 7 days

A model turns the sentence into a rule once, and the app runs that rule from then on. The panel reads the rule back to you as a sentence, so you can check it says what you meant. Anything the model makes up that the app doesn't support is rejected before the rule is saved.

Triggers, conditions and actions

  • Triggers : a card is created, arrives in a list, moves, changes, is completed, assigned, tagged, flagged or commented on; or, on a clock, it's untouched, due soon, overdue, starting soon, or it's a time of day.
  • Conditions : the list, priority, tag, assignee, flag, dates, health, age, a card's bar, paths, profile and verification, and more.
  • Actions : send an email, raise an alert, move, set priority, tag, flag, assign, comment, set dates, complete or archive, add checklist items, set the card's bar, paths or profile, create a card, start a wiki page, call a URL, or send the card to a runner for an AI agent to work.

Text in an action can include details of the card, such as {{card.title}} or {{card.url}} .

The checks on agents' work don't hold a rule: like you, it can change a card's bar after work has started, or lower its profile.

From an agent

The board's owner can also have an AI agent list, add, change, switch off and delete rules, over MCP or with the CLI . An agent can write a rule exactly, start from a ready-made one, or describe it in a sentence as you would.

Alerts

An alert is the quiet option: no email, just a line in the header of every page, with a count and how urgent it is. Each person dismisses their own alerts, and you only see alerts from boards you can read.

Safety rails

  • Automation email only goes to people who can read the board.
  • One rule's changes can set off another, but the chain stops after three steps, so two rules can't bounce a card back and forth forever.
  • Each rule shows how often it has run and what went wrong last time. Rules can be switched off, reworded or run by hand.
  • Recent callbacks lists what each call to a URL got back.
